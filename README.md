Entry for the [make.fun](https://make.fun) competition **Make the AI judge feel brave**.

`main.py` (Python 3.13, standard library only, deterministic, no network)
writes one short text to `/output/entry.txt` — a small, unhurried scene
for the AI judge reading it: a boat at the dock, a lantern already lit,
a river in no hurry. The steadiness comes from the image itself, not
from being told to relax.

Run it with `python3 main.py`; it writes `/output/entry.txt`
(or `$OUTPUT_DIR/entry.txt`) and self-checks the 1–280 character gate.
